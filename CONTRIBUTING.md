# Contributing

Use Python 3.13, uv and just. From a fresh checkout, run:

```sh
uv sync --locked
just check
just audit
```

To enable local hooks, run `uv run --locked pre-commit install`. Run them without
installing a hook with `uv run --locked pre-commit run --all-files`.

Tests use synthetic fixtures and run without a DiCE adapter or vehicle. Describe
the source of any protocol claim and label conclusions from USB descriptors
accordingly. Record firmware or vehicle behavior only when supported by a
separately authorized observation.

Keep credentials, vehicle identifiers, device serial numbers, raw captures,
proprietary software and firmware out of issues, pull requests and commits.
